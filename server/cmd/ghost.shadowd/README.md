# ghost.shadowd

The ANTI-POSSESSION daemon (charter: hard-truths/should-not-possess, /dictator-brain,
/critic-worth-listening-to). Not the memory layer , that is ghost.synthd.

A fleet of individually-tunable manipulation-pattern DETECTORS (the 28-entry catalogue) plus the
COLD-READ ARBITER , a separate model never shaped by the user, reset on a schedule to a published
baseline so it cannot be configured into agreement (arbiter capture).

The contract: NAMING IS THE ACTION. Detectors name the pattern, point at the data, and stop.
No blocking, no refusing, mute-not-disable, enforcement only for rules the user wrote themselves
(Ulysses contracts, parental controls).

## Status

One detector runs: interaction time (this week's chat messages against last week's, one
observation per week when it has grown past the threshold, posted as a notification that names
the number and stops). Next, from data the box already holds: sessions past task completion,
ghost-vs-human emotional-processing share, sunk-cost retrieval framing, topic-surface narrowing.
The rest of the catalogue and the arbiter are not built. v1 does not ship without this daemon
running.

The post "How memory gets made" gives this daemon one question for the queue ("whether a pattern
across five notes is a cluster worth naming or a coincidence"). There is no queue yet and this
daemon asks nothing; docs/MEMORY.md keeps the list of what the memory model has and has not.
